MC 联机助手 —— 先读这个
========================================================

一句话：谁玩完谁上传，下一个人开局自动拿最新的；每个人还是自己那个角色。

--------------------------------------------------------
0. 先装好（只要两样）
--------------------------------------------------------
  · Git for Windows  https://git-scm.com/download/win    一路默认
  · 和房主完全一样的整合包（Better MC [FABRIC] BMC3 / MC 1.21.1 / Fabric 0.17.2）

  ※ 不用装 Python —— MCMesh.exe 自带运行环境

--------------------------------------------------------
1. 放到 C:\Users\你的用户名\MCMesh\
   双击 MCMesh.exe
   （Windows 可能弹「已保护你的电脑」→ 更多信息 → 仍要运行，只有第一次会问）
--------------------------------------------------------

--------------------------------------------------------
2. 第一次打开会弹一张配置表，填这几项
--------------------------------------------------------
  ① 我的 ID        → 你在游戏里的名字，一字不差（yang / Phant0m_zor）
                     定了就别改：改名 = 换角色，背包/坐标全重来
  ② 整合包目录     → 你自己机器上的 ...\versions\Better MC [FABRIC] BMC3
  ③ 存档文件夹名   → 随便填（之后会自动纠正）
  ④ 启动器 exe     → 有 PCL 就选，没有就留空
  ⑤ 仓库地址       → 房主给你的 GitHub 地址（没有就留空，走 U 盘/文件夹）
  ⑥ 分支名         → 直接回车（默认 main）
     联机方式      → 选「单人存档 + 局域网」

--------------------------------------------------------
3. 以后每次玩（就 4 步）
--------------------------------------------------------
  双击 MCMesh.exe，然后：

  1) 点「拉取存档」            —— 拿最新的世界
  2) 列表里点自己名字那张卡
  3) 点「▶ 以选中身份进入游戏」 —— 自动换角色并启动游戏
  4) 进游戏 → ESC → 对局域网开放(25565) → 把 IP 发群里
     玩完先完全退出游戏 → 点「上传存档」

  第一次上传会弹浏览器让你登录 GitHub（房主得先把你加进 Collaborators）。
  连不上 GitHub 就让房主用文件夹方式给你：他点「更多 → 导出存档到文件夹」，
  你点「更多 → 从文件夹导入存档」。

--------------------------------------------------------
3.5 想在游戏里点按钮？（可选，装个模组）
--------------------------------------------------------
  把 mcmesh-1.0.0.jar 放进整合包的 mods\ 文件夹，重启游戏。
  然后进「单人游戏」，世界列表右上角就有「MCMesh 同步」：
  拉取存档 / 上传存档 / 修复成就与权限，都在游戏里点，不用切出来。

--------------------------------------------------------
4. 另外两个按钮（一般不用管）
--------------------------------------------------------
  · 作弊开关：单机存档的「允许作弊」= 管理员权限。/gamemode、/give 都靠它。
              窗口开着的时候，你退出游戏后它会自动把成就和这个开关修好
  · 右上角「我的ID ✎」：换账号、或这工具换人用时，先点这里改名字

完整的说明在同目录：使用说明书.md / .txt（看 .txt，记事本打开不乱）
卡住了：点「更多 → 体检」
